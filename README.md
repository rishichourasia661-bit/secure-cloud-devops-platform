# Secure Cloud DevOps Platform

A production-minded DevSecOps platform for securely building, testing, containerizing, and deploying a Python API to AWS.

## Project Overview

This project demonstrates modern DevOps and cloud security practices across the application delivery lifecycle.

### Technologies

- Python
- Docker
- GitHub Actions
- GitHub Container Registry
- AWS
- Terraform
- IAM
- OIDC
- Linux
- CloudWatch

### Key Capabilities

- Containerized Python API
- Automated CI/CD
- Infrastructure as Code
- Secure GitHub-to-AWS authentication
- Automated security checks
- Staging and production environments
- Application health monitoring
- Infrastructure and deployment troubleshooting

## Architecture

The platform follows a Git-based delivery workflow:

Developer → GitHub → GitHub Actions → Security Checks → Docker → GHCR → AWS Staging → Production
